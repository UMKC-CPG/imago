# Contributing to Imago

Imago is an open-source project and is developed primarily by the UMKC-CPG group. While Imago itself is not open to community contributions at the moment, contributing to this wiki and documentation is welcome.

There are primarily two ways to contribute to the documentation:
- If you have questions, troubles, or solutions, you may email Dr. Rulis with them. Good questions will be added to the FAQ, and difficulties and solutions might be added if time permits
- Fork the repository, make changes, then begin a pull request.

Forking the repository is the perferred method for contributions. And here are some things you need to know:
- We use github pages and jekyll to create our pages
   - All pages are .md files with yaml front matters
   - We use the just-the-docs theme see their website about formatting
   - The entire website is compiled and deployed from the docs/ directory. So keep all documentation to this directory.
- Verify your changes by deploying your own github page from the fork
   - Additionally, please leave it up so the Imago documentation maintainers can see your changes on a website
- In your pull request, please list all your changes, additions, and removals.
- Changes to established heirarchical structure will be scrutinized very heavily.

Other than that, thank you for your effort in contributing!
